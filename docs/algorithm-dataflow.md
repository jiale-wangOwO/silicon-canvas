# Algorithm dataflow

算法数据流的画面围绕数据对象和变换组织。硬件数据路径仍按资源、端口、存储和连接组织；系统依据源规格选择适合的表达。

## 编译方法

`algorithm_flow_plan` 保存源节点、张量形状、算子、依赖、分支汇合、状态递推与数据驻留的对应关系。输入相同，Web 和 MCP 使用相同规则生成这份方案。

图形角色、张量形状和驻留位置可由语义模型通过节点的可选 `diagram_role`、`tensor_shape`、`residency` 字段表达。给定的维度、转置、归约轴、数学表达式与条件应原样保留；缺失的信息仍按现有智能补全与来源规则处理。原有规格不需要新增字段也能使用。

画面安排由真实依赖决定：独立输入保留各自支路，在对应算子处汇合；数据张量、计算算子、归约和持久状态具有不同图形含义；循环状态走可追踪的返回通道；明确给定的驻留与分块说明数据复用。普通多输入汇合不会自动变成求和，空间排列也不代表精确周期。

张量可用简洁的矩阵、特征图或数据标记，形状紧邻对应数据；算子采用紧凑的平面符号。统一字号、短连线、有限强调色与有用途的留白建立层级。只有源规格支持时才画矩阵网格、重复次数、驻留区或时间轴。

## 生图与核对

算法主图直接使用编译提示词调用 Image Gen。生图包附带 `algorithm-flow-plan.json` 和源规格，关键端点与数学含义可逐条核对。工程附图保留原有精确资源布局流程。

最终位图需要核对独立输入、分支端点、归约含义、张量变化、状态返回与文字。源覆盖率和软件测试说明编译行为；实际图片的阅读效果另行检查。

两个可复用的示例是 [scaled dot-product attention](../examples/attention-dataflow.json) 和 [tiled online attention](../examples/online-attention-dataflow.json)。前者展示并行输入与 V 旁路，后者展示查询分块、流入 KV 与跨迭代的统计量和累加器。出处及原图观察见 [论文参考研究](algorithm-flow-reference-study.md)。

第三方原图保存在开发者本地、被 Git 忽略的 `reference_images/dataflow/`。发行包仅包含出处与原创观察，以及由本工具提示词实际生成的示例。
