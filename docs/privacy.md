# Data and privacy

## Web

模型 API Key 只留在当前页面内存。重新加载或关闭页面后需要重新输入；Key 不进入项目 JSON、ZIP、浏览器 localStorage 或日志。页面向用户选择的接口发送 `Authorization` 和设计描述，接口提供商会按其自身规则处理请求。

网页托管方提供静态页面与资源，不是模型请求的代理。运行时或字体资源的请求可能由静态主机/CDN 按其规则记录；这些资源请求不包含模型 Key。没有项目自建账户、遥测或设计上传服务。

任何网页代码都能读取该页输入，因此应使用自己信任的部署和 HTTPS 地址。自定义兼容接口必须支持浏览器 CORS；CORS 失败不能通过把 Key 填入某个陌生代理来修复。对于含保密设计的输入，应自行确认所选模型服务与使用权限。

项目内容和生图包包含设计资料。分享或上传前检查源规格、图注、提示词、假设和审查清单。

## Local MCP

本地编译与导出不需要网络模型请求。准备工具返回规格指导，宿主 Agent 随后按宿主模型服务的规则处理输入。

可选模型生成工具从本机环境配置读取 Key，将请求发送到配置的模型服务。Key 不作为工具结果返回，不写入项目或生图包。不要把真实 Key 提交到仓库；`.env.example` 只提供变量名。

导出材料写入配置的本机工作目录。使用者应按公司资料管理要求选择目录、访问权限和备份方式。
