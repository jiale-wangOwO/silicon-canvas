# AMD 官方产品图：主体、尺度与商业表达

本轮研究在 2026-10-18 浏览 AMD 官方产品页，并逐张查看四张产品图的实际像素。覆盖完整加速卡、局部揭盖封装、带散热器的显卡和整机机架。原图及来源、原始尺寸、SHA-256 只保存在已忽略的本地 `reference_images` 参考库；本文仅记录官方链接和自己的观察，没有复制官方图片。

这是一组视觉参考，不代表 Silicon Canvas 已实现相同效果，也不把厂商的实物尺寸、接口数量、裸片布局或性能参数作为通用生成默认值。

## 对渲染策略的建议

1. **先决定主体与观察范围。** 封装、裸板、整卡、服务器和机架是不同物体类别。主体尺度应来自用户要解释的对象，不能统一替换成一个带标签的金属方块。
2. **再决定装配状态。** 外观展示保留完整外壳；内部介绍才考虑揭盖、局部剖切或有限爆炸。逻辑关系不足以推导真实裸片位置、线缆数量、热界面或机械装配。
3. **视角服务于轮廓。** 展示板形、散热器和接口时，正视或低透视很有效；表达厚度、层次和整机体积时再用三分之四视角。不能把所有主体强行设成同一个等距角度。
4. **控制一处主焦点。** 细节可以丰富，但不应每个器件都高饱和、每条边都发光。金属、PCB、风扇和外壳要有不同的粗糙度与亮度；颜色只承担少量强调作用。
5. **按交付环境安排背景。** 白底图适合文档、方案书与产品对比；深色渐变可以衬托明亮封装或机架。深色背景、金色装饰和大幅留白都不是商业图的必要条件。
6. **让物体与文字各司其职。** 这四张参考主要靠物体本身表达，具体参数在网页文字区域。默认可只保留用户确实需要的短标题或标识；若任务是系统组成和数据流，应另选系统示意或工程图，不能让漂亮外壳代替信息。
7. **将真实性边界写入生成与审查。** 无机械资料时应定位为通用概念示意，避免借用真实品牌、型号、性能数字和专有外形。审查既看构图材质，也看是否增加了无依据的连接、部件或装配关系。

这些原则可以指导提示词组织，但实际成图仍需逐张检查；研究参考不能替代真实 ImageGen 的视觉与技术验收。
