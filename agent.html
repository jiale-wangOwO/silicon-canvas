手动安装与配置 ＋

需要 Python 3.11+。下载或克隆仓库后，在项目根目录运行对应安装器；它会创建独立环境，并生成 mcp-config.json 与 codex-mcp.toml。

Windows · PowerShell

.\scripts\install-mcp.ps1 -PackagePath .

macOS / Linux

bash scripts/install-mcp.sh .

将安装器生成的配置添加到支持 MCP 的客户端，由宿主通过 STDIO 启动服务。无需开启网页或本地 HTTP 服务。若使用 Windows 免 Python 发行包，请保持 EXE 与旁边的 _internal 资源目录完整；具体以安装说明为准。

可选工具 silicon_generate 可以调用本机配置的兼容模型接口；默认宿主流程使用 silicon_prepare 与 silicon_compile。

MAKE SOMETHING CLEAR

接入后，直接说你想画什么。

用 Silicon Canvas 画一个 GPU 的架构图，讲清任务如何分发到计算簇，以及共享 L2 和显存怎样连接。用图片生成工具画出来，再根据实际成图继续调整。
  1. 01

    理解设计

    Agent 调用 silicon_prepare，按返回要求整理源事实、关系和必要假设。

  2. 02

    形成绘图方案

    通过 silicon_compile 编译提示词与完整源规格，并取得这张图所需的参考材料。

  3. 03

    生成图片

    Agent 按工具返回的参考要求，调用宿主的 Image Gen，生成实际图片。

  4. 04

    看图，再改进

    检查实际图片的结构、连接与文字，根据你的反馈继续调整。编译完成不等于成图准确。

把设计和过程一起留住。

silicon_export 保存提示词、源规格、参考与图注；silicon_prepare_review 提供核对材料，方便 Agent 对照实际图片继续改进。
